## 三、本目录自己产出的文件

这些**不是**上游的，是本目录新写的 / 生成的，随时可重建：

| 路径 | 性质 | 重建方式 |
|---|---|---|
| `tools/acet_format.py` | 手写 | —（零依赖参考实现） |
| `tools/acet_cli.py` | 手写 | — |
| `tools/selftest.py` | 手写 | — |
| `tools/make_testdata.py` | 手写 | — |
| `docs/**/*.md`、`*/README.md` | 手写 | — |
| `testdata/sample_*.png` | 生成 | `python tools\make_testdata.py` |
| `testdata/synth_*.raw` / `*.bin` | 生成 | `python tools\make_testdata.py` |
| `testdata/_work/**` | 生成（临时） | `python tools\selftest.py`（每次重建；**收尾时已清理**） |
| `_selftest/run_*.txt` | 生成 | `python tools\selftest.py` 等的输出留档（已随收尾移入 `_selftest/_archive/`） |
| `_selftest/01-交叉验证报告.md` | 手写 | — |

★ `tools/__pycache__/` 是 Python 自己生成的缓存，已清理，**不必保留**。

### testdata 里的合成样品不是真实存档

`testdata/synth_*.raw` 是本目录按格式**编码**出来的字节样本（内容 = `sample_A_60colors.png`），
**不是**任何游戏的真实存档。文件名带 `synth_` 前缀就是为了避免混淆。
它们的价值：可以拿来验证任何第三方实现读得对不对。
