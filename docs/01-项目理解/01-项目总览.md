# 项目总览：mparley/ac-emblem-tool

> 一句话：**把 PC 上的 128×128 PNG 塞进 PS2《装甲核心》系列的徽章存档，也能把存档里的徽章导成 PNG。**
> 单人业余项目，MIT 许可，C++17，命令行 + wxWidgets GUI 两个前端。

* 仓库：<https://github.com/mparley/ac-emblem-tool>
* 作者：Marcellus Parley（GitHub `@mparley`）
* 语言 / 许可：C++ / **MIT**（`Copyright (c) 2021 Marcellus Parley`）
* 规模：源码 22 个文件、约 0.9 MB；含历史与全部二进制约 22 MB
* 时间跨度：2021-08-05 起，最后代码提交 **2025-02-10**，最后发行 **2025-02-11**
* 社区热度：14 star / 1 fork；最新发行包下载 250 次，v1.0.2 下载 830 次

## 它解决什么问题

《装甲核心》PS2 世代的徽章（エンブレム）是玩家自己画的 128×128 图案，存在记忆卡里。
官方编辑器只能在手柄上画；玩家想把 PC 上画好的图案传进游戏，就得直接改存档。
这个项目就是干这个的：**存档 ⇄ PNG**。

作者在 README 里交代了动机：他先找了两个现成工具，都不好用 ——
[Armoured Core 2 Emblem Tool](https://www.ps2savetools.com/download/armoured-core-2-emblem-tool/)
只吃老的 SharkPort/X-Port 格式；
[Armored Core 3 Emblem Extractor/Injector](https://www.vg-resource.com/thread-23051.html)
（vg-resource 论坛用户 Chase 的作品）导出的图是花的。于是他**参考后者的源码**，
自己盯着十六进制数据花了一天把格式搞明白，写出了这个工具。

→ 所以这个项目在谱系上是**第三代**：AC2 tool → Chase 的 AC3 tool → 本工具。
它在社区里的独特价值是：**唯一公开了 PS2 世代 AC 徽章存档完整结构、且还活着能下载到编译好的
Windows 二进制的工具**。

## 两个前端

```
acet/            格式核心库（格式知识全在这里，只有 2 个文件、约 230 行）
├── acet.h       常量（0x4440 / 0x4420 / 0x24 / 0x4000 …）与函数声明
└── acet.cpp     OffsetIndex / FindOffset / ExtractImage / InjectImage / 校验

acet-cli/        命令行版「Coke Classic™」—— 拖文件到 exe 上就能用
├── main.cpp     134 行：1 个参数 = 提取，2 个参数 = 注入
└── LodePNG/     第三方 PNG 编解码库（MIT，作者内联进仓库）

acet-gui/        wxWidgets 图形版（v0.1 才有的新东西）
├── acet-gui.cpp 主窗口：菜单 / 拖放 / 文件选择器 / 后台备份
├── ImagePanel.* 只做一件事：把 128×128 的图放大 3 倍最近邻显示
└── Info.plist / main.exe.manifest   mac / windows 的打包元数据
```

**CLI 与 GUI 的差别不只是界面**：GUI 会用 wxWidgets 做减色（quantize）、缩放、
alpha→mask 转换，所以它能直接吃任意格式的图；CLI 什么都不做，
**要求你自己先准备好 128×128、≤255 色的 PNG**。两者对"半透明"的处理也不同
（见 `07-限制与已知问题.md`）。

## 版本号里有坑，务必先看这张表

**版本号和时间顺序不一致**：`v0.1` 是 2025 年的，却比 2022 年的 `v1.0.2` 号小。

| 发行 | 日期 | 内容 | 该用哪个 |
|---|---|---|---|
| `v0.0` | 2021-08-05 | 首个 Windows 二进制，仅 CLI | 考古用 |
| `v1.0.0` | 2021-08-30 | 支持各种大小的存档格式、拖放 | |
| `v1.0.1` | 2021-08-31 | 备份 `SAVEFILE.backup`、提取叫 `SAVEFILE.png` | |
| **`v1.0.2`** | 2022-12-23 | **加入 Last Raven / Nexus / Nine Breaker** | ★ **CLI 首选** |
| **`v0.1`** | 2025-02-11 | 「半生不熟的 GUI」（作者原话）+ 附带的 `acet-cli` | ★ **GUI 首选** |

数字小的那个 `v0.1` 是**最新**的。它是作者在 `jank-gui` 分支上做完 GUI 后，
懒得想版本号就直接打了个 `v0.1`。

★ **实用结论**：想要**命令行**用 `dist/v1.0.2/acet.exe`（它是最新最全的 CLI，
而且是无依赖静态构建，拷到哪都能跑）；想要**图形界面**用 `dist/v0.1/acet-gui.exe`。

## 三个分支

| 分支 | 头提交 | 说明 |
|---|---|---|
| `main` | `fbce00c` (2025-02-10) | 发行线。`v0.1` 之后只多了一个修 CMakeLists 的提交 |
| `jank-gui` | `2572417` (2025-02-10) | GUI 的开发分支，**就是 `v0.1` 那个 tag** |
| `dev` | `9073a7f` (2025-03-11) | ★ **未发行**：PS1（AC1 / MoA）支持，半成品 |

`dev` 分支比 `main` 多 571 行，加了三件东西：

1. **PS1 记忆卡直达支持** —— 不用先导出裸文件，直接读整张 `.mcr` 记忆卡，
   用 `ExtractImageAC1()` / `InjectImageAC1()` 按「记忆卡块号 + 徽章槽号」定位，
   PS1 徽章是 **64×64、16 色**（`palette 32 字节` + `4bpp` 索引，两个像素挤一字节）；
2. **CLI 参数解析重写**（`parseArgs()`），加了 `-e` / `-i` / `-ps1 <块> <槽>` / `-nb` 等开关；
3. **`PS1Dialog`** —— GUI 里选记忆卡块和徽章槽的对话框。

作者自己的注释写着 `/*cout << "Temp help message\n";*/` —— 说明这分支确实没收尾。
**`dev` 没有发行二进制，想用得自己编译**；而且它把 AC1 的校验算法也逆出来了
（`ApplyChecksumAC1()`，对块内 `0x38e2` 字节求和后取负），这部分是**本仓库之外没有的**知识。

本目录已把这部分源码一并 clone 进 `src/ac-emblem-tool`（完整 git 历史 + 全部分支与 tag）。

## 怎么上手（最短路径）

```
1. 找到存档            见 docs/01-项目理解/02-存档格式规范.md §七
2. 提取看看            dist\v1.0.2\acet.exe  BASLUS-20435E00       → 生成 BASLUS-20435E00.png
3. 改图                必须 128×128、≤255 色
4. 写回去              dist\v1.0.2\acet.exe  BASLUS-20435E00 my.png
                       （会自动把原件备份成 BASLUS-20435E00.backup）
5. 拷回记忆卡 / 转换回去，进游戏读那个徽章存档
```

不想用官方 exe（比如想批量脚本化、想在别的系统上跑、想看清格式）：
本目录有 **零依赖的 Python 参考实现**，用法见 `tools/README.md`：

```
python tools\acet_cli.py <存档> --info     结构信息
python tools\acet_cli.py <存档>            提取 PNG
python tools\acet_cli.py <存档> <图.png>   注入
```

★ 这个 Python 实现已与官方 exe **双向交叉验证**（三种载体双向读写逐像素一致，
见 `_selftest/01-交叉验证报告.md`）—— 不是"照猫画虎"，是字节级等价。
