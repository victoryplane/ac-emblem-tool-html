# PS2《装甲核心》徽章工具 · 网页版（开发笔记）

**单个 HTML 文件、双击离线打开、别人 0 安装。** 把任意一张图变成 PS2《装甲核心》能用的徽章，
写进记忆卡；也能反过来看 / 导出卡上的徽章。

> * **技术契约**（格式 / 卡层 / 界面判据的"当前口径"）看 `SPEC.md` 与 `PORT-NOTES.md`；本文件只写"怎么构建、怎么测、怎么自查"。
> * 版本号是 `src/ui/logic/version.ts` 里的**唯一**常量；**逐版本历史由 git 记录**（`git log`），不再单独维护变更文件。
> * 上游 / 格式知识在 `..\docs\`；命令行实现与验证证据在 `..\tools\`、`..\_selftest\`。

## 一、构建（只有一步）

```powershell
node web\build.mjs        # → web\dist\emblem-tool.html（约 668 KiB；中日韩英四套文案都在里面）
```

| 命令 | 作用 |
|---|---|
| `node web\build.mjs` | 打包 + 自检（自检失败**非零退出**） |
| `node web\build.mjs --check` | 只对**已有**产物做自检，不重新打包 |
| `node web\build.mjs --verbose` | 顺带打印模块图（每个模块的依赖数 / 导出数） |

要求 **Node ≥ 22.13（本机 24.14.1）**。构建器用 `node:module` 的 `stripTypeScriptTypes()` 擦类型 ——
**没有 npm 依赖、没有 `package.json`、没有 `node_modules`、不联网。**

构建时做的自检（任一不过就非零退出）：`dist\` 里只有 1 个 html 且文件名固定 / 恰好 1 个 `<script>`、没有
`type="module"` / 抹掉注释与字符串后没有 `import`·`export` / 没有 `http://`·`src="./`·`<link>`·`fetch(` 之类外部引用 /
每个模块变换后能被 JS 引擎解析 / **`node:vm` 里用最小 DOM 桩把整包跑一遍** / **取景冒烟**（1024×600 源图，
拖动 30 次 + 滚轮 10 次 ⇒ `prepareEmblem()` **0** 次、面板刷新 **0** 次、新建 canvas **0** 个；〔确定取景〕⇒ 各 **1** 次；
〔取消〕⇒ 0 次）/ 版本号硬校验。

## 二、怎么用

1. **先完全退出 PCSX2**（它退出时会用手里的旧卡写回文件，你的改动会被覆盖），并自己备份一份卡。
2. 双击 `web\dist\emblem-tool.html`。
3. 顶栏〔选择记忆卡〕→ 选 `memcards\*.ps2`（也可以把 `.ps2` **拖到顶栏「记忆卡」那一块**）。
   ★ **选择框开在哪**（0.30）：网页**不许**指定任意路径（`startIn` 只收"已知文件夹"或一个目录句柄）⇒
   ① 点过〔选择 PCSX2 目录〕、授权还在 ⇒ **直接开在 `C:\Users\M\Documents\PCSX2\memcards`**；
   ② 否则开在**「文档」**（`C:\Users\M\Documents`；`PCSX2\memcards` 就在它下面两层）。
   Chrome / Edge（Chromium）下能拿到写句柄 ⇒ 保存时**直接覆盖原卡**；其它浏览器退化成"下载"，按提示先退出 PCSX2 再拷回。
4. 把图**拖进左上那一格**，或点〔选择 / 粘贴图片〕，或直接 **Ctrl+V**。
5. ★ 导入后**自动进入取景模式**：**拖动图片**把要的部分放进**白框**里（滚轮缩放），白框下面那行是实时读数，
   满意就〔确定取景〕。想手动再进/出：点那一格上方的〔取景〕。
6. 选作品（LR / SL / NX 有实机证据，其余标「未验证」）→ 点要写的槽 →〔写入选中槽〕。
7. 工具会：生成徽章块 → 在**内存副本**上写 → **回读**逐字节比对 + 18 段校验 + ECC 自检 → 全过才弹确认框 → 覆盖（或下载）。

> ⚠ 「卡上没有这个作品的目录」时会被**拒绝**：非 LR 的每个槽是一个完整存档目录（除徽章还有 `icon.sys` 与图标文件），
> 只建目录会写出游戏不认的半成品。解决办法：先在游戏里往那个槽存一次徽章。

## 三、界面（现状）

```
顶栏：  记忆卡 [选择记忆卡]   作品 [下拉]   v0.47    语言/Language/言語/언어 [中文▾]
        卡信息 = 锁状态（🔓 能直接覆盖保存 / 🔒 只读 · 保存=下载）+ 卡文件大小
上区：  ┌────────────────────────────────────┬──────────────────┐
        │ [选择/粘贴图片][取景] 预览倍率[4×▾] 文件名·尺寸 │ 参数（右栏）        │
        │   （没图时这一格是空的 —— 原来那句"支持拖入 / 点击选择 / Ctrl+V …"0.29 已删）  │
        │ ┌────────────────────────────────┐ │ 缩放核  [自动判断▾] │
        │ │ 当前图片（128×128，索引 0 口径）  │ │ alpha 阈值 [──●──]128│
        │ │ = 游戏所见；取景在**同一格**里切  │ │ 默认 128。半透明像素 │
        │ └────────────────────────────────┘ │ 在这一步归成全透明/全不透明│
        └────────────────────────────────────┴──────────────────┘
中部：  8 个槽位（2×4）：**上面 = 槽号 · 下面 = 缩略图**（卡片上**没有别的文字**；空槽是一个大「＋」）
        按钮：[写入选中槽] [导出 PNG] [删除槽] [另存为] [看目录项（调试）]
        〔删除槽〕删完**立刻写回卡文件**（一个确认框 + 覆盖 + 回读比对）
其下：  写卡提示 / 状态行 / 写入日志
        （0.32：写卡提示里那行"这一槽要写哪个文件"与选槽时状态行那行**都删了**；
          0.37：8 格上也不再写目录\文件 / 字节数 / 校验状态 —— 卡片只剩槽号 + 图；
          状态行只报"真发生了变化"的事：切作品 / 写卡结果 / 出错。"会覆盖哪个文件 + 请先完全退出 PCSX2"
          仍在**落盘确认框**里，见下面 §三 要点。）
最下：  ★ PCSX2 自检（全宽、**默认折叠**：点〔展开〕看结论/入口；读进文件后会自动展开一次）
```

要点（完整口径见 `SPEC.md` §四）：

* 上区 = 一格"当前图片"（**索引 0 口径** = 游戏所见）+ 右栏**参数**两格（缩放核 / alpha 阈值）；
  `.upper` = `minmax(0,1fr) minmax(190px,220px)`，**≤1100px 上下堆叠**。**不做内置像素编辑器**（理由见 `SPEC.md` §六）。
* **缩放核三档**：`自动判断` / `最近邻（像素画）` / `面积平均（照片）` —— 两档核各有明确适用面：
  像素画与整数倍缩小用最近邻（逐像素复制、不造色）；照片/大图缩小用面积平均（权重非负、和为 1，
  大比例缩小不混叠）。`自动判断` 就是这两条规则的自动版（判据落在**实际缩放倍率**上，见 `SPEC.md` §五 ③）。
* **取景是按需的**：在同一个格子里切视图 —— 固定白框 + 拖动源图 + 滚轮绕框心缩放（最小 = **128 源像素**，不许放大）；
  ★ **白框边长还能精确调**（`v0.38`）：动作行最左边是 `白框边长 [滑条] [输入框] 源像素`（步长 1 源像素，
  锚点同样是框心；输入框实时显示当前大小、也可以直接改）；〔确定取景〕〔取消〕贴在这一行的**最右边**。
  拖动期间**只改源图的 `transform`**（rAF 合帧）：参数行与"当前图片"**等〔确定取景〕才更新一次**，〔取消〕连管线都不跑
  —— 这是用户要求的行为，也是性能契约（`ui.test.ts` 有断言）。
* **8 个槽 = 当前所选作品**的槽（按**盘序列号**过滤，区域前缀 `BA`/`BI` 不参与）。
  ★ **0.37**：槽位上方那行摘要（占用/空、"本作品目录"、卡上其它作品的清单）已按用户要求**整句删除**；
  "被隐藏了什么"不许静默这条性质仍在：**只有**"本作品在卡上没目录"时会出现一条警告，它会给出
  卡上**别的作品的目录条数** + "切作品查看"（`#slot-note`）。该作品在卡上还没目录 ⇒ 8 格全空、**写入被拒绝**。
* ★ **0.43：一个事实只在一个主位讲全文**：写入被拒时，**提示区**（就在〔写入选中槽〕上方）给一行完整指令，
  状态行 / 右下角提示条只说一句话标签，**不往写入日志里记**（预检被拒 = 没发生任何事 ⇒ 日志框保持收起）。
  完整规矩见 `SPEC.md` §八 7，机制与实测见 `PORT-NOTES.md`。
* ★ **0.44：界面文字一律是纯文本**（不是 markdown）⇒ 文案里不写 `**加粗**`（会原样显示成星号），
  强调用 `★` / `⚠` / 大写。规矩见 `SPEC.md` §八 8。
* **顶栏卡信息只有两段**：锁状态 + 卡文件大小。（原来还有第三段"整卡徽章目录清单"，已删。）
* 结果只写在**页面最下面的状态行 / 写入日志**里；界面上**不放说明性长句**。
  ★ 状态行**不复述槽内容**；"会覆盖哪个文件 / 是不是覆盖 / 请先完全退出 PCSX2"在**落盘确认框**里说
  （`logic/writeGuard.ts::confirmWriteMessage()`）—— 删的是复述，不是安全提示。
  ★ 〔看目录项（调试）〕是**开关**（点第二下把日志框收起来）；其它日志（写入 / 删除）会顶掉它。
  这两条的规矩与理由见 `SPEC.md` §四 的 `★ v0.32` / `★ v0.37`。
* ★ **中/日/韩/英四语**（0.28 中英；0.47 加日/韩 —— 受众：中日欧美韩）：
  顶栏**最右**有语言下拉（`中文 / English / 日本語 / 한국어`，默认中文；浏览器语言是 ja/ko/en 时首屏自动跟随；
  手动切过就记住）。写法、四语闸门（参数个数 / `data-ja`·`data-ko` / 各自字体栈 / 逐语言判定）
  的**完整口径**见 `SPEC.md` §三 末尾 + §八；这里不重复。
* 安全提示「先完全退出 PCSX2」写在**写卡确认框**里（页脚那两行已删，提示没丢）。
* 三个内容区都**不出现滚动条**；「预览倍率」是**期望上限**，装不下就自动缩到刚好装下并在下方注明。

### PCSX2 自检怎么用（面板在页面最下面）

它解决的问题：**你在 PCSX2「设置 → 记忆卡插槽」里选的卡，可能不是游戏实际读的那张** ——
PCSX2 还有一层「每游戏设置」（`gamesettings\<序列号>_<CRC>.ini`）会**盖掉**全局设置。

| 方式 | 什么时候用 | 说明 |
|---|---|---|
| **① 选择 PCSX2 目录**（主路径） | 默认 | `showDirectoryPicker({id:'pcsx2', startIn:'documents'})`：Chrome 记住你选的目录，句柄存进 IndexedDB，下次权限还在就自动读一遍。 |
| **② 目录输入框**（兜底） | 没有 `showDirectoryPicker` 或它抛 `SecurityError` 时**自动**切过来 | `<input type="file" webkitdirectory multiple>`，按 `webkitRelativePath` 匹配，**不依赖 File System Access API**。 |
| **③ 拖进来** | 随你 | 三个文件或整个目录都收（拖目录走 `FileSystemEntry` 递归）。 |

三条路都会写明"本次来源"，读进来**立刻**出结论表。**全程只读，不写任何文件。**

### 版本号规则

* `src/ui/logic/version.ts::APP_VERSION` 是**唯一**来源（顶栏、构建日志都用它）：从 **0.1** 起**每次交付 +0.01**；
  **只有用户明确说"可以发布了"才允许进 1.x**。
* `UI_BUILD_TAG`（`M4-UI-29` 这种）是**给我们看的开发标记**（用来确认"用户打开的不是缓存页"），每次界面改动 +1。
* 打包时 `build.mjs` 把这个常量替换进顶栏（HTML 里只留 `data-app-version="v?"` 占位符），所以 JS 没跑起来也不会显示 `v?`；
  `ui.test.ts` 断言产物里的版本号与源码一致。

## 六、出了问题怎么自查

1. **第一步永远是 F12 → Console 看有没有红色报错**。红色 = JS 抛异常。本工具装了全局兜底（未捕获的异常 /
   未处理的 Promise 失败都会弹红色提示条）⇒ **"点了没反应"本身就是 bug**，请连同红字一起报。
2. **确认你打开的不是缓存页**：看顶栏版本号；开发标记在 F12 的 `EmblemToolCore.ui.buildTag`。
   对不上就关掉标签页重新双击产物（别用浏览器历史/书签打开）。
3. **提示"这张卡在磁盘上又被改过了 ⇒ 拒绝写入/操作"**：磁盘上的卡在工具读过之后被别的进程写过，最常见就是
   **PCSX2**（游戏里存了徽章，或它退出时把手里的卡写回）。Chrome 会拒绝往过期句柄上写，所以工具干脆在动手前拦住，
   **磁盘一个字节都没动**。照它给的三步：① 完全退出 PCSX2；② 重新选一次这张卡；③ 再操作一次。
   ⚠ 别用〔另存为〕存出来的副本盖回那张卡（内存副本是基于**旧的**读，会抹掉期间的改动）。
4. **"写入被拒绝"先看右下日志的红字**（`❌ 槽位 N：…`）：`卡上没有目录 …E##` ⇒ 先在游戏里存一个；
   `18 段校验不通过` / `ECC 坏页` ⇒ **没写盘**，卡还是原样；`图像不合规` ⇒ 看红字里的原因。
5. **想手查内部状态**（Console）：
   * `EmblemToolCore.ui`（界面状态与版本）、`EmblemToolCore.emblem` / `EmblemToolCore.card`（格式层 / 卡层）；
   * `EmblemToolCore.ui.cropView`（`setCropView(true)` / `applyDrag(dx,dy)` / `applyZoom(1.15)` /
     `confirmCrop()` / `cancelCrop()` / `cropInfo()` —— 不用鼠标也能走一遍取景）；
   * `EmblemToolCore.ui.imageImport.applyImportedImage({data,width,height,name}, 'x.png')`（**走真路**导入一张图）；
   * `EmblemToolCore.ui.pipeline.pipelineStats()`（★ 性能哨兵：取景拖动期间必须不动，〔确定取景〕才 +1）。

## 七、打包器的 import/export 纪律

`build.mjs` **只支持这一种子集**，遇到不支持的写法会**报错并指出文件与行号**（不静默产出坏包）：

* **支持**：具名导入（多行 / `as` 别名 / 内联 `type`）、纯副作用导入、`import type`、`export const|let|var`、
  `export function`、`export class`、`export { a, b as c }`、`export type|interface|declare`，
  以及唯一的 re-export 形式（`export` + 星号 + `as`，用于把核心层挂到 `window.EmblemToolCore` 供 F12 手查）。
* **不支持**（一律抛错）：默认导入、`import * as ns`、`export default`、动态 `import()`、`import.meta`、
  `export * from` / `export {a} from`、裸模块名、少写扩展名、循环依赖。
* **写 UI 的四条纪律**（都是踩出来的）：① 注释里别写**落单的反引号**（注释里的反引号会把后面几百行当模板字面量吃掉）；
  ② 注释里别写**标签字面量**（`<link>` 这种会被自检数成真标签）；③ 注释里别写出**被测试禁止出现的字面量**
  （注释会进产物 ⇒ 那条断言自己就红了）；④ "有没有调某个函数"这类断言要打在 `maskSource()` **之后**的源码上。
